# Mobile - MyLife App

Ứng dụng di động Portfolio & CV cá nhân tương tác cao được xây dựng bằng Flutter.

---

## 🛠️ Công nghệ sử dụng
- **Framework:** [Flutter](https://flutter.dev/)
- **Ngôn ngữ:** [Dart](https://dart.dev/)
- **Tích hợp API:** Kết nối trực tiếp với Backend C# ASP.NET Core

---

## 🚀 Hướng dẫn khởi chạy

### 1. Cài đặt dependencies
```bash
flutter pub get
```

### 2. Chạy ở môi trường Development
Kết nối thiết bị di động của bạn hoặc khởi động Emulator/Simulator, sau đó chạy:
```bash
flutter run
```
